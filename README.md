# DASHBOARD-DA-DIO
DASHBOARD DE VENDAS AULA DIO
Este projeto apresenta um Dashboard de Vendas de Videogames desenvolvido no Microsoft Excel, com o objetivo de transformar dados comerciais em informações visuais para apoiar a análise de desempenho e a tomada de decisões.

O cenário analisado envolve a comercialização de jogos de videogame e serviços relacionados, considerando diferentes períodos e modalidades de aquisição por parte dos compradores, como planos mensais, anuais e outras modalidades de contratação.

A proposta é utilizar recursos de análise de dados para identificar padrões de vendas, comportamento dos compradores, desempenho dos produtos e evolução do faturamento ao longo do tempo.
